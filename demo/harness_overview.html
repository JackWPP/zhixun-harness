结果边界：这些是公开验证集的开发结果，不是官方成绩或隐藏测试结果。第一版不接大模型、没有独立诊断小模型，也不声称已找到物理漂移原因。A 的乙醛 F1 仍为 0；B 的 RMSE 虽下降，仍差于训练均值常数对照（536.27 分钟）。

已实现的 2–4 项功能

  1. 诊断：A 类别混淆与批次差异；B 逐轴承误差及常数参照；C 训练侧运行设置聚类与工况误差。
  2. 动作：低学习率、L2、训练类别加权、训练设备均衡抽样、训练内固定小幅扰动。规则与证据写入计划。
  3. 执行和门控：同轮候选从相同已选父模型出发，恢复权重/Adam/标准化；逐轮评估并保留最佳 epoch；失败或退化不更新；记录数据/代码/父子检查点摘要、事件与耗时。

示例设置：每轮最多 3 个候选，每候选最多 5 epoch，最多 2 轮，耐心值 2，主指标最小改善阈值 0。各任务共享的候选训练预算为各自 60 秒，在 mini-batch 边界检查；不是进程硬超时。

下载与本地运行

下载 Harness 代码与使用说明下载三个任务报告、日志和检查点核验与测试结果

代码解压后，在项目根目录运行；原始 ZIP 只读，输出必须是新目录：

python -m harness run --task A --archive "C:/Users/zhao jiahao/Downloads/cpu-a-guide-20261110-v1.zip" --output "outputs/my-A-01" --epochs 5 --max-candidates 3 --rounds 1

仅依赖 NumPy。完整参数与文件结构见代码包内 harness/USAGE.txt。后续可在 strategies.py 扩展动作，或替换规则决策器；训练与验证边界不变。

测试与限制

测试覆盖：原 Adam 续训等价、冻结 scaler、拒绝验证数据进入优化器、确定性、恢复最佳轮、失败候选禁用、拒绝后保留父模型、预算中断、完整来源链与 HTML 转义。

没有在线标签回流、平台提交、LLM 工具调用或生产级进程隔离。诊断使用验证反馈，因此需防止反复选择过拟合。原始包标记 official_scoring_ready=false；正式上线、外部数据与在线更新权限仍以平台规则为准。
