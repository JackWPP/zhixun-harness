关键不在“让大模型基于官方数据跑一遍”，而在漂移处理机制与经验沉淀——模型层在漂移中变强，策略层在轮次间变聪明；两条证据链都来自受控批次流实验。

3

策略实验 白名单 + 预算

候选臂：frozen / recenter / pair / adapt（历史续训） / full；每轮 ≤3 个候选，公开验证集 selection+margin 判定。

4

门控上线 / 回滚 LLM 只能更保守

通过才 promote，失败回滚并留痕；A→full、B→adapt、C→frozen，C 的“不进化”也是实验结论。

5

经验沉淀 给下一轮用

JSONL 审计 + SQLite（lessons / strategy_stats / skill_usage）；漂移→策略→结果写入记忆，跨轮、跨 run 累积成路由与先验。
