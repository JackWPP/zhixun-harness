# 复盘：从 45.18 到 56.65，我们学到了什么

> 这不是一份“总结报告”，而是一份**给下一次比赛用的错题本**。
> 记录原则：只写真问题、真原因、真改法；不写“下次注意”这种空话。

---

## 1. 结果回顾（事实）

| 节点 | 配置 | 结果 | 关键动作 |
|---|---|---|---|
| formal #1 | 0.14.8（A 自适应 / B scratch h48 / C scratch） | **45.74**，eligible=false | not_below、records、materials 三个 gate 挂 |
| formal #2 | 0.14.9（warmup=2） | **45.18**，eligible=false | warmup 冻结 stage-01，worst_stage 0.3715→0、recovery ↓ |
| formal #3 | 0.14.12（C retain、warmup=0、材料升级） | **56.65**，eligible=false | not_below **翻 true**；只剩两个人工审核 gate |
| trial（最终） | 0.14.11 | A 0.8947 / B 155.17 / C 55.89 / NASA 9.24e10 | 额度用尽 |

客观分构成（formal #3）：mean_gain 3.35/15、recovery 3.37/5、retention 5/5、worst_stage 0.37/5、resource 0/5 → 12.09/35；主观/材料部分约 44.56/65。

**结论**：低分的直接来源不是“模型不行”，而是 **①评分口径下 objective 上限低 ②两个人工审核 gate 未核验 ③C 的 NASA 尾部**。但这三条都是事后才真正看清楚的——这就是要复盘的原因。

## 2. 做对了什么（要保留）

1. **A 的真正杠杆找对了**：泄露分析 → 发现 AA/Ethanol 方向反转 → 累积标签继续训练 + pair 固定阈值，隐藏 0.46 → **0.89**。
2. **B 的“静态后处理陷阱”识别对了**：验证集上 shrink 498 很漂亮，隐藏 735；retain 后 720，再重训 h80 到 **155**。教训是“验证集上好看的，隐藏集可能反向”。
3. **C 的“基线安全”决策对了**：C retain 让 `not_below_static_baseline` 从 false 翻 true，这是 56.65 与 45.74 的核心差别之一；用 0.3 分换 gate 是划算的。
4. **材料文档是实打实的分数**：formal #3 前把 docs/43 升级（两次 formal 复盘、记录字段说明、复现命令），总分从 45.74 → 56.65，其中约 11 分来自非客观部分。**“写清楚”本身就是竞争力**。
5. **本地同构模拟器 + 200+ 测试**：没有它，A/B 的结论不可能在 2 核 4G 的正式环境里一次跑通。

## 3. 错题本（按严重程度排序）

### 错题 1：把“公开验证集”当成“隐藏测试集”的代理

- **现象**：docs/34–35 曾报告 A “+0.147、复现平台”，后来发现隐藏代理只有 644 行、只有 3 个类别，0.4802≈0.4768 是巧合，不是复现。
- **根因**：代理切分只按行做，没有按“类别/单元/阶段”分层；验证集与隐藏流的分布、类别支撑完全不同。
- **改法（已做一部分）**：固定类别集评估、按 stage/单元分组、块 bootstrap、hidden 代理隔离；**任何“隐藏会变好”的结论必须带 support 报告和 CI**，否则只写“本地验证”。
- **下次**：数据集切分时先写“分布假设清单”，任何代理都要标注支持度（类别/单元/阶段/行数）。

### 错题 2：伪重复（n_eff = 1）

- **现象**：多“seed”实验逐位相同；campaign 的 `--seed` 没传给 full_env，submission 里 seed 又写死。
- **根因**：随机性没有端到端贯通，也没有“预测哈希”校验。
- **改法（已做）**：campaign 修复 seed 透传、manifest 双校验（tag+seed）、submission 读 `RSI_V2_SEED`。
- **下次**：每个随机实验必须同时记录 seed、行序哈希、预测哈希；只要两项相同就判“非独立”，不进入统计。

### 错题 3：合规边界靠“事后被平台抓”

- **现象**：0.14.4 的 FIT_PAIR 用训练标签拟合阈值 → 判违规；0.14.5 的 B/C continue_train 把 validation 行拿去 fit → 判违规；回归 gate 方向符号反了 → 判违规。
- **根因**：“用标签计算参数、再把参数发布/部署”这条线没有形成强制清单；代码审查只看“指标好不好”。
- **改法（已做）**：数据边界断言（`data_boundary.json`）、只用 public/train、pair 只用固定历史 delta、gate 方向归一化。
- **下次**：维护一份《合规红线清单》（训练数据边界、后处理参数来源、验证集用途、每轮真实模型调用、记录字段），每次提交前自动跑一遍“红线自检脚本”，并把清单写进测试。

### 错题 4：warmup 保护 stage，却毁了 worst_stage

- **现象**：formal #2 前 2 轮强制 retain，结果 stage-01 增益 0，worst_stage 从 0.3715 → 0，recovery 4.2 → 3.7，总分下降。
- **根因**：只想“防早期回退”，没做 stage 级收益分析；worst_stage 是按最小 stage 增益折算的，前几轮冻结直接归零。
- **改法（已做）**：warmup 默认 0；需要时用 `RSI_V2_PROBE_RETAIN` 做一次性探针。
- **下次**：任何“保护性”改动都要先在 stage 级模拟上做 A/B，尤其检查 worst_stage / recovery 这类“短板指标”。

### 错题 5：C 的 NASA 尾部 — 用平均指标选模型

- **现象**：C scratch 验证 RMSE 降 3.2%，隐藏 NASA 从 4.26e10 恶化到 9.24e10。
- **根因**：NASA 由极少数超长 RUL 行主导（err≈−300 → exp 放大），与 RMSE/平均值几乎无关；选型只看了 RMSE。
- **改法（已做）**：C 改 retain；docs/46 完整记录了尾部机制与实验（重加权爆炸、Huber 双赢但不可迁移）。
- **下次**：对这类重尾指标，选型必须看**最差单元/分位数/尾部代价**，不能看全局平均；可考虑分位数回归/极值建模，但必须通过 stage 级验证。

### 错题 6：把 trial 当 formal 的预演

- **现象**：trial A 0.8947，以为 formal 稳了；但 trial 不报 objective/gates，formal 的隐藏流与审查口径不同。
- **根因**：把“协议通过”误当“分数可复现”。
- **改法**：trial 只用于**合规认证**；formal 前必须用材料/记录自检 + gate 预算表。
- **下次**：trial/formal 名额提前分配：trial 用于“验证合规与探针”，formal 用于“锁定 + 冲分”，不要前松后紧。

### 错题 7：材料与记录到最后一刻才整理

- **现象**：前两次 formal 的 records/materials gate 一直是 false（未核验），最后一次升级文档后才明显提分。
- **根因**：把“材料”当附属品；实际它占 65 分的大头，而且需要人工审核。
- **改法（已做）**：docs/43 最终材料版（提交物、实验记录索引、复现、边界）、docs/45 审核请求。
- **下次**：从第一天就维护“材料即代码”的目录（截图、记录、SwanLab 链接、manifest 哈希），每周自动生成一版，而不是赛后补。

## 4. 下一阶段的改进优先级

### P0（下次开赛前必须完成）

1. **合规红线自检脚本**：把 7 条红线写成自动检查（数据边界、后处理来源、验证集用途、call_id、records 字段、分块上传、版本/材料一致），CI 里跑。
2. **记录字段自动校验**：对照平台 workspace_report schema，逐字段断言；缺字段直接失败，不允许“应该够”。
3. **材料自动生成器**：从 run 目录/SwanLab/manifest 自动生成材料文档和证据索引，人工只做校对。

### P1（有算法价值）

4. **重尾指标选型**：对 C 这类指标，引入分位数/尾部代价的候选评估，避免“平均分好、尾部爆炸”。
5. **stage-aware 本地代理**：按 stage 分组模拟，重点评估 worst_stage/recovery，而不是只看最终值。
6. **预算优化**：token/CPU 计量进 `resource` 字段；kernel 工具集 core + prompt 精简已验证省 18.5% token，继续压。

### P2（长期）

7. **漂移机制库**：把 A 的方向反转、B 的晚期低 RUL、C 的超长 RUL 尾部归纳成可复用的 drift pattern 与对应策略。
8. **自动材料/答辩生成**：每次 run 结束自动产出“1 页证据图 + 1 页复盘”，减少赛后补材料的时间。
