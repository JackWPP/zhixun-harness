# 外部调研需求（可直接复制给调研方 / 大模型）

> 用法：把下面「提示词」整段发给外部调研同学或支持联网检索的模型。

## 提示词

你是一名工业机器学习 / 传感器漂移方向的研究助理。请帮我做一次**有出处的、可复现的文献与数据事实调研**，不要泛泛而谈，不要编造引用。背景如下：

### 背景

我在参加一个工业模型自进化比赛，任务 A 是 **UCI Gas Sensor Array Drift Dataset (#224)** 的 6 类气体分类（128 维传感器特征；类别：Ethanol / Ethylene / Ammonia / Acetaldehyde / Acetone / Toluene）。官方只允许用 batch1 作为训练集（445 行），batch2 作为公开验证集（1244 行）；隐藏测试是后续批次的数据流，**每批会返回标签**，且评测是批次流协议。模型是一个很小的 NumPy MLP（4326 参数），部署在 CPU 上，规则上不允许打包大模型权重、不许评测期访问外部网络。

### 我观察到的异常（已用官方数据和外部 UCI 全量批次验证）

1. 模型在官方 train（batch1）上 Acetaldehyde（class 3）分类正常（F1≈0.82），但 **batch2 之后 class3 的判定方向系统性反转**：
   - 用 train 上训练的「Acetaldehyde vs Ethanol」判别方向，在 batch1 上 AUC=1.000，在 batch2 上 AUC=0.140，在 UCI batch3–10 上 AUC 分别 0.136 / 0.439 / 0.526 / 0.271 / 0.216 / 0.085 / 0.044 / 0.319。
   - 逐特征类均值差向量在 train 与 val 间的相关系数：class3 vs Ethanol = **−0.886**；其余 5 类 vs Ethanol 为 +0.79 ~ +0.999。
   - batch2 中 109 行 Acetaldehyde 有 108 行被判成 Ethanol，Acetaldehyde F1=0，直接压住 macro-F1（0.7140）。
2. 该现象不是整体协变量偏移、不是局部 gain/offset：逐段/滑窗 recenter、CORAL、目标域 z-map、EM label-shift、无监督两簇阈值都试过，全部无效或显著变差（见下方“已排除方向”）。
3. 用 oracle 阈值把 AA/Ethanol 判定方向翻回来，官方 validation macro-F1 可从 0.7140 上到 **0.8728**，说明潜力很大，但需要知道“该类在目标批的方向/阈值”。

### 我希望你调研的问题

**Q1（最重要，数据事实核查）**：UCI Gas Sensor Array Drift Dataset（#224，Vergara 2012 及相关论文、UCI README、Zenodo 22820993 的 gas-sensor-drift-ml-benchmark、以及后续复现论文）中，是否已有关于 **Acetaldehyde（class 3）与 Ethanol（class 1）在 batch2 之后响应方向反转、类条件特征漂移、或标签语义变化**的记载？原论文/dataset 说明里是否提到“某些气体在批次间响应极性/幅度反向”、传感器老化/中毒、或该数据集的已知标签问题？请给出具体出处（论文名、章节/表号、链接），没有就说没有。

**Q2（方法文献）**：概念漂移里针对 **“类别条件方向反转 / label semantics drift / class-conditional concept drift”**（不只是 prior shift 或 covariate shift）的检测与在线校准方法有哪些？特别关注：
   - 有标签延迟、但每批会返回上一批标签的在线学习/校准；
   - 只用无标签目标批做方向恢复是否可能（test-time adaptation / 无监督方向估计）；
   - 小模型、小样本（每批几百到一千行）、CPU 可跑的方法。
请按“是否适配我的约束”排序，给出 3–5 个候选方法，每个说明假设、输入、输出、计算量、失败条件。

**Q3（协议/评测事实）**：比赛会议纪要说明“每批带标签、且会累计返回历史数据”。请帮我确认这类工业评测里，**静态单次预测 vs 批次流**下，baseline 通常如何计分；如果只有静态 predict 入口、拿不到隐藏标签，业界通常怎么做合法的目标域校准（不能使用隐藏标签）？

**Q4（baseline 口径）**：官方静态基线（A 0.7140）是否通常就是同一个 checkpoint 直接 predict？有没有可能它已做过某种校准？这会影响我们如何声明提升。

### 已排除方向（不要在这上面浪费时间）

加宽网络/结构迁移、class-weighted CE、过采样/标签平滑、输入增广、随机种子集成、CORAL/TCA 域适应、目标域 z-map、EM label-shift、温度缩放、熵最小化、局部/滑窗 recenter、无监督 k-means 阈值翻转。以上都试过，对“class3 方向反转”无效。

### 输出要求

1. 先给一张「事实核查表」：说法 / 出处（论文+链接+表号或页码）/ 可信度（高/中/低/未找到）。
2. 再给「方法候选表」：方法 / 关键假设 / 是否适配我的约束 / 计算量 / 预期增益 / 失败风险。
3. 最后给「可执行建议」：按 P0/P1/P2 排序，最多 5 条，必须能在 CPU、仅 numpy 的小模型上落地。
4. 所有引用必须给可点击链接；没有来源的推测请明确标注“推测”。
5. 如果 Q1 查不到，请直接说“未找到相关记载”，不要编造。
