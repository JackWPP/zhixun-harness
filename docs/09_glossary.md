# 09 · 术语表

> 写给不熟悉这个赛道的人。按拼音/字母混合排序，中文词条按首字。

---

## A

**Adam** — 一种自适应学习率优化器，维护每个参数的一阶矩（动量）和二阶矩（方差）。
本项目的 checkpoint **连 Adam 状态一起保存**，所以续训和连续训练逐位等价。

**AutoML** — 自动机器学习。本 harness 的"6 配方 + 门控"是 AutoML 最朴素的一种形态，
但它**没有搜索空间**（只有 6 个离散点），所以算不上真正的 AutoML。

## B

**Bootstrap（自助法）** — 从现有样本中有放回地重采样，用来估计指标的置信区间。
本项目用 2000 次配对 bootstrap 判断"提升是不是噪声"。
**配对**的意思是：对每个验证样本，同时取基线预测和新模型预测，算差值再重采样。

**Batch（批次）** — 任务 A 的数据来自 16 个连续批次的气体传感器测量，
不同批次之间温度/湿度漂移，导致特征分布不同。训练只用 batch-1，验证只用 batch-2，
这是**故意的跨域切分**。

## C

**C-MAPSS** — NASA 的商用模块化航空推进系统仿真数据集，任务 C 的来源。
四个子集 FD001–FD004，难度递增（FD002/FD004 有多种工况）。

**Checkpoint（检查点）** — 模型参数 + 归一化统计量 + Adam 状态 + 元数据的打包文件。
本项目用 `.npz` 格式（ZIP_STORED，固定时间戳，`allow_pickle=False`）。

**CORAL** — 一种无监督域适应方法，对齐源域和目标域特征的二阶统计量（均值+协方差）。
**这是修 A 任务乙醛问题的备选方案之一**。

## D

**Drift（漂移）** — 输入特征的分布随时间/环境变化。任务 A 的核心难点。

**Domain Adaptation（域适应）** — 在源域有标签、目标域无（或少量）标签的情况下，
让模型在目标域上也能工作。任务 A 的 batch-1→batch-2 是标准的无监督域适应场景。

## E

**Epoch** — 把训练集完整过一遍。本项目基线 A 跑 20 个 epoch，B/C 跑 15 个。

## F

**F1 / macro-F1** — F1 是精确率和召回率的调和平均。**macro-F1** 是逐类算 F1 再取算术平均，
所以**小类和大类权重相同**。任务 A 用 macro-F1 做主指标，这意味着
只有 5 个样本的 Toluene 和有 532 个样本的 Acetone **同样重要**。

**Finding（发现）** — 诊断模块输出的单条结论，结构是
`{code, severity, title, evidence, recommendation}`。

## G

**Gain（增益）** — `improvement()` 的返回值。分类任务 = 新 F1 − 旧 F1；
回归任务 = 旧 RMSE − 新 RMSE。**正数才可能被接受。**

**Gate（门控）** — 决定"候选模型是否替换当前模型"的判定逻辑。
本项目是 `gain > min_improvement`（严格大于）。参数 `min_improvement` 默认 0.0。

**Gradient Clipping（梯度裁剪）** — 把梯度范数限制在 5.0 以内，防止梯度爆炸。
基线有，harness 继承。

## H

**Holdout（留出集）** — 从训练集里再切一部分出来，**只用于模型选择**，
不参与训练也不用于最终报告。本项目目前**没有**，这是方法缺陷（见 `06_risks.md` R3）。

**Harness** — 本项目的核心对象。原意是"挽具/测试框架"，
这里指"套在模型外面的自动训练控制层"。

## L

**L2 / 权重衰减** — 在损失里加 `λ‖w‖²` 惩罚，抑制过拟合。本项目 6 个配方里
有 5 个带 L2，λ ∈ {0.001, 0.002, 0.003}。

**Learning Rate（学习率）** — 本项目 harness 里**永远**是父模型的 0.3 倍
（`harness/strategies.py:212`）。

**LLM** — 大语言模型。**本项目完全不含 LLM**（已用 grep 验证）。

## M

**MLP（多层感知机）** — 全连接神经网络。三个任务的模型都是
`输入 → tanh(hidden) → 输出` 的**单隐层** MLP。

**Macro / Micro** — macro 是"先分类算再平均"，micro 是"先汇总混淆矩阵再算"。
macro 对小类敏感，micro 被大类主导。

## N

**NASA Score** — C-MAPSS 的经典非对称评分：
早期预测（低估 RUL）惩罚小，晚期预测（高估 RUL）惩罚大。
公式含 `exp`，所以对个别大误差极其敏感。本项目实现里是**求和**，
得到 5.8e9 的无意义数字（见 `06_risks.md` R14）。

## O

**Overfit（过拟合）** — 训练集表现好、验证集差。任务 B 的基线就是典型：
train RMSE 233，val RMSE 681。

## P

**Patience** — 早停的容忍轮数。本项目默认 2：连续 2 个 epoch 没提升就停。

**Partial Epoch** — 因为时间预算耗尽而没跑完的 epoch。本项目**不会**把它落地
（`harness/training.py:400`），这是很正确的设计。

## R

**RSI（Recursive Self-Improvement，递归自我改进）** — 系统能改进"自己改进的能力"。
**本项目没有实现**。它实现了自我诊断和自我更新，但没有实现自主生成新假设。
这是赛题标题里的核心概念，也是答辩时最容易被追问的点。

**RMSE（均方根误差）** — `sqrt(mean((pred−truth)²))`。任务 B/C 的主指标。

**RUL（Remaining Useful Life，剩余使用寿命）** — 从当前时刻到失效还剩多久。
B 的单位是分钟，C 的单位是循环。

**Rule-based（基于规则）** — 用 if/else 和阈值做决策。本项目的 `decision_mode="rule"`
就是它，三次 demo 全部用的这个。

## S

**Seed（随机种子）** — 控制初始化、数据打乱顺序等随机性。
**本项目最大的方法论问题之一**：A 任务的 +0.0126 增益，换 10 个种子重跑 **0/10 能复现**。

**Strategy（策略/配方）** — 一个完整的超参组合 `{lr, l2, noise_std, balanced_*, epochs, ...}`。
本项目只有 6 个，全部硬编码在 `harness/strategies.py:111`。

**Snapshot（快照）** — 单帧输入。任务 C 是纯快照模型（`window_sizes: [1]`），
任务 B 也是。**这是 B 表现差的结构性原因。**

## T

**tanh** — 双曲正切激活函数，输出范围 (−1, 1)。基线隐藏层用它。

**Transductive** — 训练时使用了测试样本的**特征**（但不使用标签）。
任务 A 若用验证集特征做域适应，就属于 transductive 设定。

## U

**Unsupervised（无监督）** — 不使用标签。域适应里的 CORAL、BN 统计量重估都是无监督的。

## X

**XJTU-SY** — 西安交大与沈阳机床联合发布的轴承全寿命数据集。任务 B 的来源。
15 个轴承（条件 1/2/3 各 5 个），本项目用了 12 个（9 训 3 验）。

## Z

**Z-score 标准化** — `(x − mean) / std`。本项目用**训练集**的 mean/std，
并且**冻结**（续训时不允许改），这是正确的做法。

## 本项目专有名词

| 词 | 含义 |
|---|---|
| **候选（candidate）** | 一次"某配方续训 N 个 epoch"的完整尝试，产出独立 checkpoint |
| **轮（round）** | 一次"诊断 → 选配方 → 跑 3 个候选 → 门控"的完整循环。本项目最多 2 轮 |
| **经验池（experience buffer）** | 记录每次候选的 12 维状态向量、配方、增益、是否被接受 |
| **状态向量** | 12 维浮点向量，喂给策略小模型。**项目里有两套互不兼容的定义**（见 `04_harness_audit.md` §4.2） |
| **策略小模型（StrategyRecommenderMLP）** | 12→24→6 的 ReLU MLP，试图学习"什么状态该选什么配方"。**从未被调用过** |
| **交付物（selected）** | 门控接受后最终保存的 checkpoint，在 `selected/checkpoint.npz` |
| **包（bundle）** | `prepare_bundle()` 解出来的 `{train, validation, checkpoint}` 三元组，带角色隔离 |
